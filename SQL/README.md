# SQL — PostgreSQL

Курс по PostgreSQL (учебная модель retail/sales: товары, заказы, магазины, остатки).  
Пройдены блоки **1–6**: для блоков 1–5 решены все практические задания; блок 6 — CASE, оконные функции и CTE.

## Блок 1 — SELECT

**Умею:** строить выборки с проекцией столбцов, алиасами, `LIMIT`, сортировкой, вычисляемыми выражениями и обработкой `NULL` (`COALESCE`, `NULLIF`, `concat_ws`).

Примеры: первые 20 товаров; `margin = listprice - standardcost` с сортировкой по убыванию.

## Блок 2 — WHERE

**Умею:** фильтровать по условиям, диапазонам, спискам, шаблонам (`LIKE`/`ILIKE`), датам и `NULL`.

Примеры: активные товары с ценой ≥ 500; заказы за последние 14 дней; остатки ниже `reorderpoint`.

## Блок 3 — JOIN

**Умею:** соединять таблицы через `INNER JOIN` и `LEFT JOIN`, строить цепочки и находить «дыры» через `LEFT JOIN` + `IS NULL`.

Примеры: товар → подкатегория → категория; заказ с ФИО клиента через `LEFT JOIN` к `person`.

## Блок 4 — GROUP BY / HAVING

**Умею:** агрегировать (`COUNT`, `SUM`, `MIN`/`MAX`/`AVG`), группировать и отсекать группы через `HAVING`.

Примеры: топ товаров по выручке; категории с суммарной выручкой > 1000.

## Блок 5 — подзапросы и CTE

**Умею:** писать подзапросы (`IN`, `EXISTS`/`NOT EXISTS`, корреляция) и CTE для расчётов и сверки сумм.

Примеры: товары дороже средней цены; CTE со сверкой `totaldue` и суммы строк заказа.

## Блок 6 — CASE и оконные функции

**Умею:** сегментировать данные через `CASE`; ранжировать (`ROW_NUMBER`, `RANK`, `DENSE_RANK`); считать `SUM`/`AVG` `OVER` с `PARTITION BY`; строить top-N в группе, долю строки (`NULLIF`) и накопительный итог.

Примеры: топ-5 самых дорогих товаров в каждой подкатегории (`CTE` + `ROW_NUMBER`); накопительный `running_total` по заказам во времени; рейтинг магазинов по выручке (`RANK`).

---

**Skills (одна строка):** PostgreSQL — SELECT/WHERE/JOIN, GROUP BY/HAVING, подзапросы и CTE, CASE, оконные функции (`ROW_NUMBER`/`RANK`, `SUM`/`AVG OVER`, накопительные итоги, top-N в группе) на схеме продаж и складских остатков (блоки 1–6).
